# Task-Management-Dashboard
A responsive Kanban-style task management dashboard built with vanilla HTML, CSS, and JavaScript. Add, move, delete, and drag-and-drop tasks across columns, with saved progress.

Task Management Dashboard is a lightweight Kanban board for organizing work across stages. Built with plain HTML, CSS, and JavaScript, it lets you create tasks, move them between columns, delete them, and reorder them with drag and drop. Tasks are saved in the browser, column counters update automatically, and the layout adapts to any screen size.
